# Git-Happens-Fall-2026-Midterm-Project
Coffee prices and Production Analysis
The project examines Arabica and Robusta coffee prices and production. It uses Python and pandas to clean and prepare the datasets for analysis. 
The project structure is as follows - 
code/prices.py - cleans Arabica and Robusta coffee price data
code/supply.py - cleans Arabica and Robusta coffee production data 
data/raw/ - contains the original datasets 
data/clean/ - contains the cleaned datasets generated by the Python scripts
requirements.txt - lists the python packages required to run the project 

Reproducibility:
All data cleaning is performed using Python. No datasets are manually modified in Excel or any other software.
Step 1: Clone the repository - git clone https://github.com/saakship19/Git-Happens-Fall-2026-Midterm-Project.git
cd Git-Happens-Fall-2026-Midterm-Project
Step 2: Install the required packages - Make sure Python 3 is installed, then run: python3 -m pip install -r requirements.txt
Step 3: Run the data cleaning scripts - run the following commands from the main project directory - python3 code/prices.py and python3 code/supply.py 
The scripts read the raw datasets from data/raw/,perform the necessary cleaning operations, and save the cleaned datasets in data/clean/.
Step 4- Generated datasets : The price-cleaning script generates: data/clean/prices_monthly.csv, data/clean/prices.csv, data/clean/price_arabica_clean.csv, data/clean/price_robusta_clean.csv
The production-cleaning script generates: 
data/clean/production_arabica_clean.csv, data/clean/production_robusta_clean.csv
Data Sources: 
The raw datasets used in this project are:
data/raw/arabica.csv, data/raw/robusta.csv, data/raw/psd_coffee.csv
The raw files should be included in the repository so that the cleaning process can be reproduced without manually downloading or modifying the datasets. 
Reproducibility Notes - 
All cleaning operations are performed programmatically using pandas. The scripts use relative paths and should be executed from the project's root directory. Running the cleaning scripts regenerates the cleaned datasets from the original raw files.
